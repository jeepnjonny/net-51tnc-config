WebSocket → TCP Bridge

      
    

    

      
Browsers cannot open raw TCP connections. This small Python relay listens for WebSocket connections from this page and forwards them to the TNC device over TCP.

      
Requires Python 3.7+  ·  one-time setup  ·  runs locally

      
1. Download bridge.py using the button below

      
2. Install dependency: pip install websockets

      
3. Run the bridge: python3 bridge.py

      
4. Set Bridge URL to ws://localhost:8765 and click Connect

      
Binds to localhost only by default. Run python3 bridge.py --help for bind host/port options.
